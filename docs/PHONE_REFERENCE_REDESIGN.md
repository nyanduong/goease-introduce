# Product preview — supplied mobile reference

The three-step preview is rebuilt as sharp HTML using the supplied GoEase poster as its visual reference: warm cream surfaces, teal form controls, orange creation action, rounded fields and itinerary rows. The create-trip and itinerary screens follow the reference's structure. The budget screen is a complementary concept using the same palette and typography; all monetary values remain sample data.

The surrounding composition uses topographic contours, moving dotted routes and floating destination cards placed beside the device on wide screens and above it on narrower screens. Text follows the shared Noto Sans typography roles.

Local verification: production build and five motion-policy tests pass; Chrome interaction checks cover the three preview steps, next/back actions, changing itinerary days and VI/EN switching. Layouts checked at desktop, 1024px and 390px widths. This is a website concept, not a connected mobile-app session.
