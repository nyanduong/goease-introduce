## Current WebGL aircraft revision

The primary aircraft now uses real mesh geometry rendered with Three.js, not the generated aircraft sprite. Source: `src/hero-aircraft.js`, built with esbuild to `dist/hero-aircraft.js`. The generated sprite remains only as a WebGL fallback. The bay now uses a photographic terrain layer with animated water, independently moving boat, reflection, wake and drifting clouds; see `LIVING_BAY_ASSETS.md` for source prompts and implementation.

The aircraft has a curved fuselage, bevelled swept wings, winglets, tail surfaces, nacelles with rotating fans, cockpit and passenger glazing. A continuous 20-second spatial orbit changes heading, pitch, bank and perspective size. Orientation uses exponential quaternion smoothing; resize and pause renders no longer reset the frame timestamp. Environment reflections, directional lighting, self shadows, navigation lights and two engine wake ribbons plus a bounded pool of 420 soft vapour particles supply detail. Vapour is emitted in world space, drifts, expands and fades over 4.8 seconds; this is an art-directed effect rather than a flight-physics simulation. Wing surfaces now use rounded airfoil sections with camber and dihedral, and passenger windows follow the fuselage radius. Shared pause, hidden document, offscreen, open dialog and reduced-motion states stop the rendering loop. Pixel ratio is capped at 1.75.

Rebuild with `npm ci` then `npm run build`. Runtime assets are self-contained in dist. Three.js MIT attribution is retained in `dist/THREE-LICENSE.txt`.

## Slogan departure and mountain depth revision

The aircraft now departs from the measured end of `#hero-title em`, climbs for 5.5 seconds, and joins a continuous 20-second orbit around the cliffs. The launch curve matches the orbit's arrival position and velocity. Cruise stays between bay coordinates Y=160 and Y=204, above the waterline at approximately Y=96. Its bank follows path curvature, and apparent size changes with distance.

The aircraft and vapour trails use the same orthographic bay coordinate system. An invisible depth-writing cutout samples the exact landscape alpha above the waterline: rear segments at negative Z are hidden by cliff pixels, front segments at positive Z remain visible. This is a depth-composited landscape using the existing photographic asset, not a new fully modelled mountain mesh. The canvas extends to the slogan anchor while the bay retains its existing screen placement. Viewport and font changes recalculate that anchor without resetting the animation clock.
