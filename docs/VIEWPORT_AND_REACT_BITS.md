# Refinements — runway, viewport-fit device, React Bits effects

- Aircraft taxi uses quadratic acceleration for 3.2 seconds. The orange underline uses that same route progress, with a small lead, and stays drawn after departure. The climb joins both the runway and the mountain orbit with continuous velocity. Animation follows existing visibility, motion and reduced-motion controls.
- Device preview uses a 350 × 744 titanium-style frame with inset Dynamic Island and camera lens. All three native HTML screens use a compact layout. A ResizeObserver sizes the full device to the viewport height and stage width; no internal scrolling or clipped footer buttons. Redundant explanatory copy is omitted inside the small preview while the fields, timeline, category totals and controls remain.
- App Store uses midnight blue; Google Play uses jade green. `dist/specular-buttons.js` adapts the actual React Bits WebGL2 SpecularButton shader and perimeter/pointer calculations to existing native buttons. Missing WebGL2 leaves fully working CSS buttons.
- `dist/download-gallery.js` adapts React Bits DepthCarousel depth/tilt/brightness math to a native requestAnimationFrame tween. Auto advance is 4 seconds, transition 850 ms. Supports pointer dragging, left/right keyboard navigation and the existing four selectors. Each destination label travels with its image. Hidden pages, dialogs, global pause, reduced motion and focus suspend autoplay.
- React Bits sources: https://reactbits.dev/r/SpecularButton-JS-CSS.json and https://reactbits.dev/r/DepthCarousel-JS-CSS.json. Retrieved 2026-10-16. Copyright David Haz; MIT + Commons Clause notice retained in `dist/vendor/react-bits-LICENSE.md`.

Verification: production build/static contracts; 8 Node tests, including acceleration and velocity continuity. Chrome at 1366 × 768 and 390 × 844: all three panels have scrollHeight equal to clientHeight (600 px), device fits the viewport when brought into view, no horizontal overflow. Both platform dialogs and carousel keyboard/manual selection checked; autoplay visibly advances, global pause stops it. Local `?flight-frame=1.6` verifies the taxi phase (underline .295), `?flight-frame=5` verifies takeoff after completed underline (1). These are browser checks with responsive viewport emulation, not tests on physical iPhone hardware.
